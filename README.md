# Hotel-Booking-Data-Analysis-Dashboard-using-Power-Bi


## Project Overview
This project was developed as a final project following a one-month Data Analysis training program at the Information Technology Institute (ITI).

The project focuses on analyzing hotel booking data using Power BI to explore booking trends, revenue performance, cancellations, and customer behavior.

## Objectives
- Analyze hotel booking patterns and trends.
- Evaluate key performance indicators (KPIs).
- Explore revenue and cancellation performance.
- Understand customer segments and room-related insights.
- Build an interactive dashboard to support data-driven decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and calculated metrics
- Data modeling and interactive visualizations

## Project Workflow
1. Data loading and exploration.
2. Data cleaning and transformation.
3. Data modeling and relationship management.
4. KPI and DAX measure development.
5. Dashboard design and visualization.
6. Insights and performance analysis.

## Key Performance Indicators
- Total Bookings
- Average Daily Rate (ADR)
- Occupancy Rate
- Cancellation Rate
- Total Revenue

## Dashboard Pages
- **Overview:** Main KPIs and booking performance.
- **Booking Analysis:** Booking trends and hotel-related comparisons.
- **Revenue Analysis:** Revenue trends and performance.
- **Room & Customer Analysis:** Room-related metrics and customer segments.
